Panduan Deployment ke Railway

Aplikasi ini dirancang untuk dapat langsung di-deploy ke Railway menggunakan Dockerfile yang telah disediakan.

# Langkah 1: Push ke GitHub yang sudah dibuat
git remote add origin https://github.com/afrizalyusni/parafarase-turnitin-otomatis.git
git branch -M main
git push -u origin main
Langkah 2: Sambungkan ke Railway
  1. Buka railway.app lalu klik New Project.
  2. Pilih Deploy from GitHub repo dan pilih repository afrizalyusni/parafarase-turnitin-otomatis.
  3. Tambahkan Service PostgreSQL di Railway. Railway akan otomatis mengatur variabel DATABASE_URL.
  4. Pada tab Variables, tambahkan (opsional untuk AI): GEMINI_API_KEY.
  5. Railway akan otomatis mem-build Dockerfile dan meluncurkan aplikasi dengan port yang sesuai!
